SOLIDWORKS TEAM CALENDAR

クイックガイド（使い方説明書）

3D CADチーム（小峠・佐藤・ヤイン・栃木）向けのSolidWorks利用スケジュール管理アプリです。時間帯の重複を自動で防止し、社内サーバー上の共有DBファイルでデータを同期します。

1 事前準備

  • 推奨ブラウザ： Google Chrome または Microsoft Edge
  • 規定DBフォルダ：
    Z:\10.技術CAD\00_共通\11_3DCAD\Solidworks Team Calendar DB
  • 共有DBファイル： SOLIDWORKS_GROUP_DB.JSON
  • （任意）HTMLファイルと同じフォルダに image_30ffc4.png を配置すると、SolidWorksロゴが表示されます。

2 ログインと権限

  • 初回起動時： ユーザー選択画面で自分の名前を選択します（ブラウザに自動記憶されます）。
  • 自分の行（ マーク付き）： 予定の追加・編集・削除・ドラッグ＆ドロップが可能です。
  • 他のメンバーの行： 閲覧のみとなっており、誤操作を防止します。
  • ユーザー切り替え： 画面右上の名前の横にあるログアウトアイコン（）から変更できます。

3 DB連携と同期（重要）

初回設定（各PCで1回のみ）
  1. 画面上部の DB読込（または DB変更）をクリックします。規定の Z:\... パスが自動コピーされます。
  2. ファイル選択画面が開いたら、アドレスバーで Ctrl + V → Enter を押し、フォルダ内の SOLIDWORKS_GROUP_DB.JSON を選択します。
  • 2回目以降の起動： 前回のファイルを記憶し、起動時に自動でDBを読み込みます（ブラウザの確認画面が出た場合は OK を押してください）。
  • 変更の保存： DB保存 をクリックすると、共有DBファイルに直接上書き保存されます。
  • DBファイルの変更： DB変更 ボタン（またはツールバーのDB連携ステータス）からいつでも変更可能です。
  • ブラウザへの一時保存： 一時保存 で一時バックアップし、隣の履歴アイコン（）から復元できます。

4 カレンダー操作

  • 表示切替： 週（週間表示） / 日（日間表示・7:00～19:00）。日付テキストをクリックするとカレンダーピッカーが開きます。
  • 予定の登録・編集： 自分の行の空きセルまたは + ボタンをクリック（デフォルト時間：08:00 ～ 10:00、5分単位、10色のカラーラベル選択可能）。
  • ドラッグ＆ドロップ： 予定ブロックを別の日へドラッグして日程移動できます。メンバー間で時間が重複する場合は自動でブロックされます。

5 ステータス表示とテーマ

予定

選択したカラーで表示されます。

作業中

開始時間になると自動で赤色になります。

完了

終了時間を過ぎると自動でグレーになります。

外観テーマ： Windows / ブラウザの設定に合わせてライトモード・ダークモード（純黒）が自動で切り替わります。
